PROYECTO CINE - MISMA ESTRUCTURA DEL HOTEL, CON REPORTE REAL

1. Extrae el ZIP en una carpeta nueva.
2. Abre la carpeta Proyecto_final con IntelliJ y utiliza JDK 21.
3. Si abres el pom.xml como Maven, recarga sus dependencias.
4. Ejecuta TestConexion; luego puedes ejecutar los tests de cada entidad.
5. Ejecuta HelloApplication para abrir la aplicación.

También puedes abrir PROBAR_CONEXION.cmd o ABRIR_CINE.cmd.
Incluye JavaFX y SQLite en lib para ejecutar sin depender de la importación Maven.
Los scripts usan C:/Program Files/Java/jdk-21, que es tu instalación actual.
La lista de SDK de IntelliJ pertenece al IDE: si no reconoce el SDK llamado 21,
selecciona tu JDK 21 en Project Structure > Project SDK.

BASE DE DATOS

El ZIP no incluye otra base con datos de ejemplo.

REPORTE DEL DÍA
Abre Reportes del Día en el menú.
La fecha predeterminada es hoy en Perú. Puedes elegir otra fecha.
El reporte muestra película, cliente, entradas, total y hora de cada venta.
Calcula el dinero vendido, las entradas vendidas y la cantidad de ventas.
Pulsa Actualizar después de registrar, editar o eliminar ventas.
Las fechas se filtran por el día peruano y las horas se muestran en Perú.

En la base revisada, las dos ventas existentes son del 19/10/2026:
2 ventas, 7 entradas y S/ 56.00.
Si consultas una fecha sin ventas, debe mostrar cero y una tabla vacía.

TESTS
TestConexion: comprueba la conexión.
TestPelicula, TestSala, TestFuncion y TestVenta: menús con insertar, listar,
buscar por ID, actualizar y eliminar.
Los datos que ingreses desde estos menús se guardan en tu base real.
Antes de registrar funciones, crea películas y salas; antes de vender, crea funciones.
Para eliminar registros relacionados, empieza por ventas y sigue con funciones.

TestReporte: muestra el reporte de hoy en consola.
Para otra fecha, coloca 2026-10-19 en Program arguments de TestReporte en IntelliJ.
No es necesario crear clientes para que el reporte funcione; se utiliza el nombre
que ya guarda cada venta.
